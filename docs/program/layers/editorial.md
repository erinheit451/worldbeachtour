## What it is
The four-tier page system (T1 Legendary / T2 Featured / T3 Field Guide / T4 Stub).
The E-E-A-T + brand layer that makes the data trustworthy to humans and gives Google
an author ("Written by Erin Rose"). Runs as an independent concurrent track.

## Relationship to the program
- Tier 1/2 = hand-authored editorial (the current gold loop). Brand + trust + the
  quality bar (`manila-bay-beach-1` reference).
- Tier 3/4 = programmatic, owned by [distribution-products](distribution-products.md)
  #1 — fed by the data layers, not hand-authored.
- The data program feeds editorial (computed attributes become page facts) and
  editorial feeds authority (trust signals Google + humans need to cite the data).

## Depends on
Runs independently. Does not block and is not blocked by the data stack rank.
